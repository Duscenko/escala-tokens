## Using these tokens

**In code** — import `variables.css` and reference the custom properties:

```css
.card {
  background: var(--color-bg-primary);
  border: 1px solid var(--color-border-secondary);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-sm);
  padding: var(--spacing-4);
}
```

Dark mode applies via the `.dark` class on `<html>`.

**In Figma** — install the Scalable Designs Sync plugin and import `tokens.json` (or point its Live Sync tab at your published endpoint). Primitives, semantic themes and typography land as Figma Variables.

**Never hardcode values** — if a color, size or shadow isn't a token here, it doesn't belong in the product. Extend this system first, then use the token.
