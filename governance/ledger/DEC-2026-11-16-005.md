# DEC-2026-11-16-005 · The country picker is an anchored Popover on every viewport; Sheet is for drawers

- **Date:** 2026-11-16 · **Owner:** Cesar Durango · **Status:** Decided (owner brief; ported in this loop)
- **Finding:** CMP-012 (issue #26).

## Decision
1. **The phone field's country picker is an anchored Popover on every viewport, a phone included.** Sheet is for drawers, filters and mobile menus, not for a list tied to one field. Width = the field's (`--radix-popover-trigger-width`), it flips above the field when there is no room, its height comes from `window.visualViewport` (never 100vh), the search is not focused on a touch device, and the ~200-row list is windowed.
2. **Sheet** is the Figma Sheet (1648:1577): the Modal's Dialog with an edge anchor (right · left · bottom). `CartDrawer` and `FilterDrawer` are built on it (side `right` on desktop, `bottom` on a phone). CMP-008 is Fixed in code.

## Consequence
The Figma flow 1662:717 draws the mobile picker as a Sheet instance (frames 1662:736 and 1662:738); it contradicts the flow's own note and this decision, and was not edited (the file is read-only here). The two frames need redrawing. The other decisions taken while building are listed in CMP-012.
