# DEC-2026-11-20-001 · Generator: places on the left, by name; the inspector only edits

- **Date:** 2026-11-20 · **Owner:** Cesar Durango · **Status:** Proposed — built on `feat/generator-left-nav`, waiting for the owner's review
- **Source:** owner's request after the DS Manager review; plan `design-plans/generator-left-nav.md`

## Decision
1. Variables and Components get a left nav column (`WorkspaceNavColumn`) that lists the places of the mode by name.
   The right inspector keeps only what edits.
2. Board, Home and Code keep their layout: the Board needs its full canvas; Home and Code have no navigation problem.
3. The column folds, per mode, remembered per browser (not design state), and starts folded below 1360px. Folded, Variables
   keeps its foundation icons and its Collections + Groups return to the inspector.

4. Shape (owner's pick, proposal C): the column is the left pane of the canvas card, and the mode rail shrinks to a
   56px icon strip on the page chrome. Rejected: A (rail and column fused in one island), B (places nested under the
   active mode in one rail).
