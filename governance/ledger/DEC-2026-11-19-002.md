# DEC-2026-11-19-002 · One code size, in a fixed mono family

- **Date:** 2026-11-19 · **Owner:** Cesar Durango · **Status:** Decided
- **Source:** Figma → Storybook handoff 2026-11-19, §1 and §7

## Context
Backup codes and the secret key of AuthTwoFactorSetup need a monospaced text style. The file had none: Kbd draws its own 12 / 11 px.

## Decision
One `Type/code` style: `role/code/*` → `size/text-md` (14 / 21 on the file's scale), `weight/regular`, tracking 0, family `font-family-mono` = Geist Mono
(a hidden primitive, like `font-family-body`), the same on Desktop, Tablet and Mobile. Kbd is unchanged. The six-digit authenticator code stays on
`type.heading-xs` (Inter) with tabular figures.

## Consequence
- Code (foundations pull, `governance/runs/2026-11-19-pull-unversioned.json`): type role `code` (`src/lib/typeRoles.ts`), a third family slot `mono`,
  CSS `--font-family-mono` and `--text-code-*` (with `-tablet` / `-mobile` twins), `monoFontFamily` in tokens.json (additive), `font-family-mono` and
  `role/code/*` in the Typography collection of the W3C / Figma export.
- The mono family is fixed for every system: it is not a picker in the configurator. Making it a choice is a scope decision for the owner.
- Geist Mono (OFL) loads through the project's font loader (`loadGoogleFont`), fallback `monospace`.
- Consumers today: AuthTwoFactorSetup backup codes and the secret key value. Nothing else.
