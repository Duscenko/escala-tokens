# DEC-2026-11-18-004 · Input: every Type has every Size; field icons are subtle

- **Date:** 2026-11-18 · **Owner:** Cesar Durango · **Status:** Decided
- **Figma:** [Input](https://www.figma.com/design/7j5zukN5HpihGVJMmyjA20/?node-id=4-12380)

## 1 · Size for every Type
`sm · default · lg` exist for all 11 Types: 32 · 40 · 48 tall, icon 16 · 20 · 20, text-md tier at sm and default, text-lg at lg.
The caret of phone and currency-select stays 16. `Field` keeps the control's Type when its Size changes.

## 2 · Field icons
Leading, trailing, clear, chevron, carets and calendar bind `Content/subtle` in every state but Disabled (`Content/disabled`), in
Input, Combobox and DatePickerTrigger. The typed value and the add-ons stay `Content/primary`. Not changed: NumberInput steppers, InputTag chips.

## 3 · Known legacy
The file binds the Input text to Typography primitives (`size/text-md`, `size/text-lg`), not a type role. The code reads
`type.body-md` (14/21) and `type.body-lg` (16/25), which carry the same values. It read `type.placeholder` (12/18) until this change. Logged as a finding.
