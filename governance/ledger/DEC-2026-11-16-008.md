# DEC-2026-11-16-008 · Only Escala components: the shadcn-only components with no Figma twin leave the catalogue

- **Date:** 2026-11-16 · **Owner:** Cesar Durango · **Status:** Decided

## Decision
The catalogue held 26 components with no set in the Figma file (`figmaSet: null` in `spec/contracts/index.json`). The owner's rule ("no quiero nada de shadcn, solo quiero los componentes de Escala", 2026-11-16): a component is in the system only if it is an Escala component, which means it has a Figma set or is a part that one of them uses.

| Outcome | Components |
|---|---|
| Removed (code, recipe, catalogue entry, specimen, snippet, contract) | Toggle · AppStoreBadge · InputGroup · StatusBadge · Icon · FileFormat · Collapsible · AlertDialog · Drawer · HoverCard · Item · Attachment · Message · Bubble · Resizable · Carousel · Chart · Skeleton · Empty · NavigationMenu · Command · Navbar, plus the `escala-ui/_skeleton/` folder |
| Kept: parts that Escala components use | Label (Field) · Spinner (the Loading state of Button, Switch, Textarea, InputTag, DatePicker) · Card (the `Container: card` of the Auth blocks, and the configurator's artefacts) |
| Kept: in Figma, snapshot stale | Sheet (`1652:8`) |

What replaces the removed ones: presence is `AvatarStatus`; an input with icons is `Input` with `leading` / `trailing`; a drawer is `Sheet` with `side="bottom"`; a confirmation is `Modal` (and the Overlay blocks); a preview card is `Popover`; an empty state is `TableEmpty`; a header is `AppHeader`.

## Consequence
- Code that started from a shadcn skeleton and has a Figma twin (Button, Badge, Input, Field…) stays: it is Escala code now. `LICENSE-shadcn.md` stays because that code is derived from MIT sources.
- The Figma plugin is not touched yet (owner, 2026-11-16): its CATALOG still builds the removed sets. `componentRecipesPluginParity.test.ts` lists them as `RETIRED_ON_WEB`. Removing them from the plugin is a separate change.
- Label, Spinner and Card have no Figma set and no Storybook story (`codeOnly`). Next step: draw them in Figma, or fold them into the sets that use them.
- The 22 public pages `/components/<Name>` of the removed components are gone from the sitemap. Old links now 404.
