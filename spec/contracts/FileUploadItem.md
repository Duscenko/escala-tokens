## Usage

One row per file under a FileUploadDropzone. Status follows the upload: queued, uploading (progress), paused, completed, error (with its reason). sm for dense lists.

## Accessibility

Every action is an IconButton with its aria-label (Pause, Resume, Remove, Retry, Change, Download). The bar is role="progressbar" with aria-valuenow. Announce completed, removed and failed files from the FileUpload's live region.
