## Behaviour

**Popover** (radix-ui, dialog-non-modal). Focus moves into the content on open and back to the trigger on close; outside click dismisses.
- `Space / Enter` opens / closes from the trigger
- `Escape` closes and returns focus to the trigger
- `Tab` moves through the popover content

**Own source** (toolbar (inside a non-modal Popover)). The picker is a role="toolbar" with one roving tab stop; each reaction pill outside it is its own button.
- `ArrowRight / ArrowDown` moves to the next reaction in the picker
- `ArrowLeft / ArrowUp` moves to the previous reaction
- `Home / End` moves to the first / last reaction
- `Enter / Space` picks the focused reaction
- `Escape` closes the picker and returns focus to the trigger (Radix Popover)

## Usage

Use under a post, comment or message to collect quick reactions. A pill whose count reaches zero leaves the row. For a single like or favourite use a toggle IconButton; for a score use RatingGroup.

## Accessibility

role="group" named "Reactions". Each pill is a toggle button (aria-pressed) named "{reaction}, {count} reactions, you reacted". Removing the last count moves focus to the neighbour pill or the trigger. Every change is announced in a role="status" region.
