## Usage

Use where several floating actions share one entry point (create → photo, edit, share…). The trigger's icon swaps plus → close when open. Give every icon-only item an accessible name.

## Accessibility

role="group" with an aria-label. The trigger is a native `<button>` with aria-expanded; every item needs an accessible name (its label prop) since fan items are icon-only.
