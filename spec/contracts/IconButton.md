## Usage

Use in toolbars, table rows and dialog headers where the icon is unambiguous. Always give it an aria-label; an action that needs words is a Button.

## Accessibility

Native `<button>` with a required aria-label (there is no visible text). Disabled sets aria-disabled; loading sets aria-busy.
