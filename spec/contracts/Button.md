## Usage

Use default · solid for the single most important action on a surface (one per view); secondary for the rest; critical · solid for an irreversible action and critical · outline for a risky one next to a safe one. Icon-only actions are IconButton.

## Accessibility

Native `<button>` (or the child with asChild). Disabled sets aria-disabled; loading sets aria-busy. The label is the accessible name; an icon-only action is IconButton.
