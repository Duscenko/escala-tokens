## Usage

Use inside Calendar for each date of the month grid. Pin Selected, RangeStart, RangeMiddle or RangeEnd for the chosen days, Today for today and Outside for the neighbouring months.

## Accessibility

A real button; Disabled and Unavailable set disabled. Give it the full date as its accessible name when the number alone is not enough.
