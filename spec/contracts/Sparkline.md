# Sparkline — component contract

> GENERATED by `npm run gen:contracts` from `spec/contracts/Sparkline.json` — never edit. Authored notes: `design-plans/sparkline-contract.md`.

A compact trend next to a value, with no axes or gridlines: a monotone line over a soft area, with a dot on the last point. Default binds the neutral chart series; success and critical use the Status roles because they carry meaning; secondary is a quiet grey.

## Usage

Use beside a number to show where it came from (a metric card, a table cell). Variant success when up is good and critical when down is bad; default when the direction has no judgement. For a full chart with axes use a charting layer, not this.

## Accessibility

role="img" with a required aria-label that states the trend ("Daily active users, up 7.2 % this week"); the drawing itself is hidden from assistive tech. The line draws once on mount (use-reveal) and new data cross-fades (use-color); reduced motion is instant.
