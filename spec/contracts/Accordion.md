## Behaviour

**Accordion** (radix-ui, accordion). Each trigger is a button in the tab order; the panel is labelled by its trigger.
- `Space / Enter` toggles the focused section
- `ArrowDown / ArrowUp` moves focus to the next / previous trigger
- `Home / End` moves focus to the first / last trigger

## Usage

Use for several stacked sections (FAQ, settings). For a single expandable region use Collapsible.

## Accessibility

Each trigger is a button inside a heading with aria-expanded; Enter / Space toggles, arrows move between triggers.
