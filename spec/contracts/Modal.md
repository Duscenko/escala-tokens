## Behaviour

**Dialog** (radix-ui, dialog-modal). Focus moves into the dialog on open, is trapped while open and returns to the trigger on close; the page behind is inert.
- `Escape` closes the dialog and returns focus to the trigger
- `Tab / Shift+Tab` cycles focus inside the dialog (focus trap)

ARIA in the source: aria-label

## Usage

Use for a decision or a short task that needs full attention (a confirmation, a small form). Not for notifications: use a Toast or an Alert.

## Accessibility

role="dialog", aria-modal="true", labelled by the title (aria-labelledby) and described by the description. Focus is trapped; Escape and the close button dismiss; focus returns to the trigger.
