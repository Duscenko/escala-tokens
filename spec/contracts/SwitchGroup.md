## Behaviour

**Switch** (radix-ui, switch). One tab stop, role="switch" with aria-checked.
- `Space / Enter` toggles on / off

ARIA in the source: role=switch · aria-describedby · aria-disabled · aria-invalid · aria-label

## Usage

Use for one labelled setting. The whole row is a label, so clicking the text toggles the switch.

## Accessibility

The row is a <label htmlFor> around the Radix switch; description and footer are linked with aria-describedby.
