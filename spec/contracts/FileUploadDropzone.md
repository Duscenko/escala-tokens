## Usage

Use at the top of a FileUpload, or alone where files are the whole task. lg for an empty page, default in a form, sm in a dense row. Dragging tints it accent; Invalid needs a visible message (it replaces the title).

## Accessibility

The Button is the keyboard path (Tab, Enter / Space opens the picker); the drop area itself takes no focus. aria-disabled when disabled, aria-invalid with a visible message when invalid.
