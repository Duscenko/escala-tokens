## Behaviour

**OTPInput** (input-otp). One real input behind the slots; autocomplete="one-time-code".
- `Digits / letters` fill the next slot
- `Backspace` clears the previous slot
- `ArrowLeft / ArrowRight` move between slots
- `Paste (Cmd/Ctrl+V)` fills every slot at once

ARIA in the source: role=group · role=separator · aria-label

## Usage

Use for one-time codes (sign-in, verification). Set length to the code length; labels and the error text come from Field.

## Accessibility

One real input with autocomplete="one-time-code"; the slots are presentational. Give it a label (Field, or aria-label); on Invalid expose the error through aria-describedby.
