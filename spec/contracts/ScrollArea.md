## Behaviour

**ScrollArea** (radix-ui). Native scrolling; the custom scrollbars are not focusable.
- `Arrow keys / PageUp / PageDown` scroll the viewport natively when it has focus

ARIA in the source: aria-label

## Usage

Use inside panels and menus with bounded height or width. Never trap page scroll; give the viewport an accessible name when it holds primary content.

## Accessibility

The viewport is focusable and scrolls with the arrows, PageUp / PageDown and Home / End; the bars are aria-hidden. Add aria-label when it holds primary content.
