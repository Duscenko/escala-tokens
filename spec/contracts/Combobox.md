## Behaviour

**Own source** (combobox (editable, list autocomplete)). Focus stays in the text field; the active option is aria-activedescendant. Leaving the field closes the list.
- `ArrowDown / ArrowUp` opens the list when closed; moves the active option when open
- `Enter` picks the active option
- `Escape` closes the list and clears the typed query
- `Typing` filters the list and opens it
- Source: src/components/escala-ui/combobox.tsx · the input onKeyDown / onBlur · story `Playground`

ARIA in the source: role=combobox · role=group · role=none · role=option · role=status · aria-activedescendant · aria-autocomplete · aria-busy · aria-controls · aria-describedby · aria-disabled · aria-expanded · aria-invalid · aria-label · aria-labelledby · aria-selected

## Usage

Use when options exceed ~10 items or need search. For short lists, plain Select is enough. Keep a visible label (Field) and expose the error text through aria-describedby.

## Accessibility

role="combobox" on the input with aria-expanded, aria-controls and aria-activedescendant; arrow keys move through the options, Enter chooses, Escape closes; aria-invalid on Invalid.
