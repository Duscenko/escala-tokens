## Behaviour

**Own source** (radio group). One tab stop (the checked option); disabled options are skipped.
- `ArrowRight / ArrowDown` moves to the next option and selects it (wraps)
- `ArrowLeft / ArrowUp` moves to the previous option and selects it (wraps)
- `Home / End` moves to the first / last option and selects it
- Source: src/components/escala-ui/segmented-control.tsx · handleKeyDown · story `Playground`

ARIA in the source: role=radio · role=radiogroup · aria-checked · aria-disabled · aria-label

## Usage

Use for 2–5 exclusive options of the same data (e.g. Day / Week / Month). Use RadioGroup for long labels or more options, TabMenu to switch views, ButtonGroup for independent actions.

## Accessibility

role="radiogroup"; each segment role="radio" with aria-checked. One tab stop; the arrow keys move and select.
