## Usage

Use for free-form text over one line (messages, descriptions, notes). Labels, hints and error text come from Field. Show the resize glyph when the expected length varies.

## Accessibility

Give it a visible label (Field, or aria-label). On Invalid set aria-invalid and expose the error text through aria-describedby (Field does both). Loading sets aria-busy.
