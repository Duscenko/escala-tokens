## Usage

Use for a message about the product or the page around it. Horizontal is the full-width banner above or below the header, vertical a boxed message in content. For auto-dismissing feedback use Toast, for form validation Field.

## Accessibility

role="alert". Convey severity with the icon and the text as well as colour, and give the close button an accessible name.
