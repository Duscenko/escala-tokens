## Behaviour

**Own source**. The text input is the tab stop; clicking anywhere in the box focuses it. Each chip's remove button is its own tab stop.
- `Enter / ,` commits the draft as a tag
- `Backspace` on an empty draft, takes the last tag back
- Source: src/components/escala-ui/input-tag.tsx · the input onKeyDown · story `Playground`

ARIA in the source: role=option · aria-busy · aria-describedby · aria-disabled · aria-invalid · aria-label · aria-labelledby · aria-selected

## Usage

Use for open-ended multi-values (emails, labels). For a known list, prefer Combobox. Keep a visible label (Field) and expose the error text through aria-describedby.

## Accessibility

A real text input; Enter or comma commits a tag, Backspace on an empty draft removes the last one. Each ✕ is named "Remove {tag}". Announce added and removed tags to screen readers and expose the error through aria-describedby.
