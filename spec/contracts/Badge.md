- Source: src/components/escala-ui/badge.tsx · story `Playground`

## Usage

Use to label or count (a plan, a status, "+5 more"). For presence (online / away), use Status Badge. Never as a button. An icon-only badge needs an accessible name.

## Accessibility

Static text — not focusable. Colour is never the only signal: the label says what it means.
