The text field: a box with the field inside it, at three sizes on the Size roles (sm 32 · default 40 · lg 48). Eleven types compose their own parts — phone and currency-select open a select, currency, url and tag carry a prefix, password a show / hide toggle, upload a Browse button, copy-link a Copy button, search the ⌘ K shortcut.

## Usage

Wrap it in a Field with a FieldLabel. Pick the type for the value it holds (phone, currency, password, url…); any other HTML type works on the default layout. For an add-on the types do not cover, use Input Group.

## Accessibility

The field is a native `<input>` with its keyboard (inputmode) and autofill hint per type; pair it with a FieldLabel (htmlFor) or an aria-label. The select addon is a native `<select>` with its own name; Browse, Copy and the password toggle are buttons with names; the shortcut keys are `<kbd>`.
