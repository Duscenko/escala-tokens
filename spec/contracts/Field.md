# Field — component contract

> GENERATED by `npm run gen:contracts` from `spec/contracts/Field.json` — never edit. Authored notes: `design-plans/field-contract.md`.

A labelled form field: a label with an optional required marker and trailing link, one form control, and helper or error text. Field never draws the control — it wires the Input (or Textarea, Combobox, NumberInput, InputTag, DatePickerTrigger, InputOTP) you give it.

## Usage

Wrap a form control that needs a visible label. Use a bare control only where no visible label is needed (search). Match the control to the Field size; Invalid shows the error, Disabled disables the control and dims the texts.

## Accessibility

role="group". The label is a <label htmlFor> on the control; description and error reach it through aria-describedby; aria-invalid on Invalid, disabled on Disabled, aria-required with required.
