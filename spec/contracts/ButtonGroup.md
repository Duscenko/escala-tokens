# Button Group — component contract

> GENERATED by `npm run gen:contracts` from `spec/contracts/ButtonGroup.json` — never edit. Authored notes: `design-plans/button-group-contract.md`.

A joined row or column of up to five ButtonGroupItem segments sharing one surface, outer radius and Shadow/xs. The group sets every segment's Variant and Size and puts a ButtonGroupDivider between them.

## Usage

Use for 2–5 related actions or views that read as one control (Previous · Today · Next, Day · Week · Month). Mark the selected segment with active. Shape pill is horizontal only.

## Accessibility

role="group" — give it an aria-label. Each segment is a native `<button>`; a selected one carries aria-pressed. Icon-only segments need an aria-label.
