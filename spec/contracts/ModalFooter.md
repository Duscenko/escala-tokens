## Behaviour

**Dialog** (radix-ui, dialog-modal). Focus moves into the dialog on open, is trapped while open and returns to the trigger on close; the page behind is inert.
- `Escape` closes the dialog and returns focus to the trigger
- `Tab / Shift+Tab` cycles focus inside the dialog (focus trap)

ARIA in the source: aria-label

## Usage

Inline puts the actions at the end, primary last; stacked gives full-width buttons for narrow viewports.

## Accessibility

Put the primary action last in inline order; the buttons keep their own focus order.
