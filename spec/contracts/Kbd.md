## Usage

Size follows the icon of the control it sits in: xs in menus and a small Input, sm in a default or large Input and in tooltips, default in standalone shortcut lists. One Kbd per key, never a whole shortcut string.

## Accessibility

Rendered as `<kbd>`, which assistive tech announces as keyboard input. Spell modifier names in an aria-label when the glyph alone is ambiguous.
